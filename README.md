Some notebooks originate from external educational/tutorial material and retain their original authorship inside the files. This repository should therefore be treated as a **study/reference archive, not as original portfolio work**.

It is being retained rather than deleted, but current project work should be evaluated through the dedicated AI and engineering repositories on this profile.
