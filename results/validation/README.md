# Independent validation

Generated by:

```bash
python -m pip install -r requirements-validation.txt
python examples/generate_external_validation_results.py
```

The benchmark uses pinned **QuTiP 5.3.1** and **PyLCP 1.0.2** through their public APIs. No fitted parameter is used to suppress a discrepancy.

## Matched results

| Benchmark | Result | Meaning |
|---|---:|---|
| Two-level steady-state population vs QuTiP | max abs. difference `5.55e-17` | OBE convention/steady state independently verified |
| Two-level transient/decay vs QuTiP | within committed numerical tolerances | time evolution independently verified |
| 1-D two-beam force vs PyLCP | max relative difference `7.93e-15` | normalized Doppler-force implementation independently verified |
| 87Rb ground Zeeman spectrum vs PyLCP | max difference about `0.57 Hz` | ground hyperfine–Zeeman spectrum independently verified over tested fields |

![Independent software comparison](independent_software_comparison.png)

The accompanying [`external_validation.npz`](external_validation.npz) stores raw internal/external curves, matched parameters, error metrics, software versions, and the validation matrix.

## Important boundary

The PyLCP force benchmark is a **normalized two-level public-API comparison**, not a full 87Rb D2 multilevel MOT validation. Likewise, the Zeeman comparison verifies the atomic magnetic spectrum, not the laser-coupled 24-state force.

The complete 24-state moving 87Rb D2 OBE is implemented and internally tested, but its multilevel force/populations remain an external-validation target. See [the full validation document](../../docs/validation.md) for the current matrix and remaining gates.
