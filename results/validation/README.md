# Independent validation

Generated by `python examples/generate_external_validation_results.py` with the
pinned optional packages in `requirements-validation.txt`. The NPZ contains all
matched parameters, raw curves, error metrics, software versions, and the
validation matrix. The PyLCP force comparison is a normalized two-level public-
API benchmark—not a full 87Rb D2 multilevel comparison. Literature comparisons
are labeled trend-only where assumptions are unmatched.
