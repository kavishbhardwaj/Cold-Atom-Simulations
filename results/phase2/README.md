# Phase-2 multilevel rate-equation results

Generated with `python examples/generate_phase2_results.py` from
`configs/rb87_phase2_rate_equation.yaml`.

The model contains 24 explicit populations: 87Rb 5S1/2 F=1,2 and 5P3/2
F'=0,1,2,3 including all Zeeman sublevels. Cooling and repump are distinct
six-beam families. The figures are Level-B model diagnostics—not OBE,
sub-Doppler, experimental, or temperature predictions.

`phase2_reference.npz` stores all plotted arrays and JSON metadata. Each PNG was
saved at 220 dpi and has a corresponding SVG generated from the same figure.
