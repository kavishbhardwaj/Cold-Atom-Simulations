# Magnetic apparatus results

Generated by `python examples/generate_magnetic_apparatus_results.py`.
The calibration is synthetic and illustrative, not a measured laboratory
apparatus. Maps and Maxwell checks use segmented Biot-Savart coils. The
imperfection table reports residual vectors, effective MOT-centre shifts and a
static 24-state OBE coherence diagnostic; it deliberately does not claim PGC
temperature or universal tolerances.
