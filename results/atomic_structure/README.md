# Vector hyperfine–Zeeman results

Generated with `python examples/generate_vector_zeeman_results.py`. The exact
Hamiltonian uses a field-independent uncoupled basis, includes magnetic-dipole
and electric-quadrupole hyperfine structure, and consumes the complete magnetic
field vector. PNG figures are displayed in the [results gallery](../README.md);
SVG alternatives and `vector_zeeman_reference.npz` retain vector/numerical data.
