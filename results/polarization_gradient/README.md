# Polarization-gradient results

`polarization_gradient_reference.npz` and the lattice/friction figures are
generated by `python examples/generate_polarization_gradient_results.py`.  They
use an adiabatic **population** model with a fixed quantization axis.  The axial
field curve is only a projected-Bz diagnostic; the code now rejects transverse
fields rather than presenting them as vector physics.  Its recoil tensor omits
internal-state and dipole-force noise, so no quantitative temperature is stored.

`vector_residual_obe.npz` and `vector_residual_obe.png` are generated by
`python examples/generate_vector_residual_field_results.py`.  They use the full
24-state vector-Zeeman OBE for static states at v=0 and explicitly compare Bx,
By and Bz over 0--1 G.  This establishes vector mixing/coherence diagnostics,
not PGC friction: a converged moving lattice average and matched OBE force-noise
tensor are still required before quoting beta, temperature, or a 10% residual-
field threshold.
